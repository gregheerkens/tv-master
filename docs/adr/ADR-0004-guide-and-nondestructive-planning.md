# ADR 0004: Classic guide, evidence-based health and isolated planning

Status: accepted from the user's 2026-11-11 guide/manager request and visual correction.

Use an SD 640×480, 4:3 guide surface with flat colors, dense rows and hard selection
states. Keep a single live player across full-PIP, bottom-third and TV-only modes.
Prefer the dated October 2000 Scientific-Atlanta reference to undated later guide
imagery. The desktop manager can use the provisional TV MASTER manual aesthetic.

Historical airings and known continuity requirements remain separate from owned
media and published broadcasts. Evidence state is explicit. Imported history can
constrain future composition; gaps are not erased when matching media is absent.
Explicit recipe substitutions remain labeled and cannot rewrite published slots.

Manager forecasts use an isolated database copy. Arbitrary analysis dates do not
change the live station's fixed clock or 72-hour horizon. Report footage coverage,
unique inventory, repetition, historical evidence and known segment requirements
separately. Only checksum-identical source repair can restore existing playback
without changing broadcast identity or timing.

The adapter remains a local browser application. Actual TV hardware and source-
specific historical scraping remain independent next milestones. No new analyzer,
AI, upscaler or hosted-service dependency is introduced.
